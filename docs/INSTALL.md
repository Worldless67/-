# Установка на mcpehost.ru
1. Собери JAR (GitHub Actions или `mvn package`).
2. Панель → Файлы → `plugins/` → загрузи JAR.
3. `resource_packs/` → папка `FrizResourcePack` → распакуй пак туда.
4. Перезапусти сервер. Спавн построится автоматически.
5. В nukkit.yml: force-resources: true.
6. При входе телефон предложит скачать ресурс-пак — согласись.
