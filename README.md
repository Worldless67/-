# FrizProject 1.9.0 — FrizMine Bedrock
Плагин для Nukkit-MOT 1.2.0 (Bedrock 1.21.114), Java 17.

## Сборка
GitHub Actions (`.github/workflows/build.yml`) или локально `mvn package`.

## Установка на хост (mcpehost.ru)
1. Панель → Файлы → `plugins/` → загрузить JAR.
2. Ресурс-пак распаковать в `resource_packs/FrizResourcePack/`.
3. Перезапустить. Спавн строится при первом старте.
4. В `nukkit.yml`: `force-resources: true`.
